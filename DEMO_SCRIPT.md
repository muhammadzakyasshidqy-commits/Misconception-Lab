# 4-Minute Demo Script

0:00–0:25 — Problem
Show a normal score dashboard. Explain that “wrong” is not one diagnosis: concept selection, procedure, attention, and confidence failures need different interventions.

0:25–0:55 — Product
Open Misconception Lab. Explain that each mistake becomes evidence in a causal learning profile.

0:55–1:40 — Live interaction
Record a Probability error with “Wrong concept selected” and 20% confidence. Show the concept node rise and the system propose a discriminating next test.

1:40–2:20 — Second failure mode
Record a high-confidence procedure error. Show how the graph changes more cautiously because high confidence produces different evidence weight.

2:20–2:55 — Technical design
Show core.js. Explain the transparent evidence function, ranking, recommendation selection, browser persistence, and deterministic tests.

2:55–3:30 — Impact
Explain how this reduces random repetition and gives students/teachers a compact model of why errors happen.

3:30–3:55 — Limitations and roadmap
State that today the learner/teacher labels the initial suspected cause. Future work will infer causes from solution traces and confidence calibration.

3:55–4:00 — Close
“Misconception Lab turns mistakes from red Xs into testable hypotheses.”
